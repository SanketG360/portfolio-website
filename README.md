# Sanket Godse - Portfolio Website

A premium, modern portfolio website showcasing backend engineering expertise, distributed systems knowledge, and real-time architecture capabilities.

## 🚀 Features

- **Premium Design**: Modern, dark-themed UI with glassmorphism effects and neon accents
- **Smooth Animations**: Framer Motion powered animations and transitions
- **Responsive**: Fully responsive design optimized for all devices
- **Performance**: Fast loading with optimized assets and lazy loading
- **SEO Optimized**: Meta tags and semantic HTML for better search visibility

## 🛠️ Tech Stack

- **React.js** - UI library
- **TypeScript** - Type safety
- **Vite** - Build tool
- **Tailwind CSS** - Styling
- **Framer Motion** - Animations
- **React Router** - Navigation
- **Lucide React** - Icons

## 📦 Installation

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 📝 Customization

Update personal information in `src/data/portfolio.ts`:

```typescript
export const personalInfo = {
  name: "Your Name",
  title: "Your Title",
  description: "Your Description",
  email: "your.email@example.com",
  github: "https://github.com/yourusername",
  linkedin: "https://linkedin.com/in/yourusername",
  leetcode: "https://leetcode.com/yourusername",
};
```
